A newspaper front page in a single picture, summing up Sunday 22 November 2026 for the make.fun news-image-20261122 bounty. The lead story is the US envoys' trip to Moscow after the Abu Dhabi trilateral talks; below it sit the two tanker attacks near Hormuz, the Sparta II drone strike in the Gulf of Finland, and the COP31 talks running into a second overtime day, with a strip of smaller stories along the bottom.

## How to run

```sh
python3 build_image.py   # redraws entry.png
python3 main.py          # copies entry.png to $MAKEFUN_OUTPUT_DIR (or /output)
```

The front page is drawn with Pillow in `build_image.py`; `main.py` is a plain standard-library copy of the finished `entry.png`.
